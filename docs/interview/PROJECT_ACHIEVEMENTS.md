## 项目概述

**项目名称**: 基于 YOLOv8 的钢材表面缺陷半监督检测系统

**数据集**: NEU-DET（钢铁表面缺陷检测）
- 6 类缺陷: crazing（裂纹）、inclusion（夹杂）、patches（斑块）、pitted_surface（点蚀）、rolled-in_scale（氧化皮）、scratches（划痕）
- 图像尺寸: 200×200 px
- 标注数据: 378 张（30%）| 无标注数据: 882 张（70%）

**核心成果**: 在 30% 标注数据的半监督场景下，构建了完整的伪标签生成→质量筛选→联合训练 pipeline，验证了动态置信度和一致性正则的有效性。

### 2.2 动态置信度阈值

**核心问题**: 固定阈值对所有类别一刀切，但不同类别检测难度差异极大。

**自适应公式**:

```
threshold_c = base_conf + λ × (1 - norm_AP_c)

其中 norm_AP_c = (AP_c - min_AP) / (max_AP - min_AP)
```

**配置**: base_conf=0.65, λ=0.25, 阈值限制在 [0.3, 0.95]

**各类别阈值示例**:

| 类别 | AP | norm_AP | 阈值 |
|------|-----|---------|------|
| scratches | 0.75 | 1.00 | 0.65 |
| inclusion | 0.60 | 0.50 | 0.775 |
| patches | 0.55 | 0.40 | 0.85 |
| rolled-in_scale | 0.50 | 0.30 | 0.925 |
| pitted_surface | 0.45 | 0.15 | 1.00 (clamped) |
| crazing | 0.40 | 0.00 | 0.95 |

**核心代码**:

```python
def _compute_adaptive_threshold(self, class_id, base_conf=0.65, lambda_val=0.25):
    ap = self.baseline_ap[class_id]
    norm = (ap - min(self.baseline_ap)) / (max(self.baseline_ap) - min(self.baseline_ap) + 1e-9)
    threshold = base_conf + lambda_val * (1 - norm)
    return max(0.3, min(0.95, threshold))
```

### 2.3 翻转一致性正则

**核心思想**: 水平翻转是视角不变变换——同一图像的翻转版本应该给出相同的检测结果。如果原图和翻转图的预测不一致，说明该检测结果不可靠。

**流程**:

```
原图预测 ──────────────────────────────┐
    │                                   │
    ▼                                   ▼
┌────────┐   翻转图预测         ┌────────┐
│ Boxes  │ ──────────────────→ │ Boxes  │
└────────┘   (x' = 1 - x)     └────────┘
    │                                   │
    └────────────┬─────────────────────┘
                 ▼
        ┌──────────────────┐
        │ IoU匹配 + 类别一致 │
        │ IoU ≥ 0.6 才保留  │
        └────────┬─────────┘
                 ▼
        保留伪标签 + 取min(conf_orig, conf_flip)
```

**关键设计**: 取 min 置信度是**悲观融合**——只有两个视图都高度确信才给高置信度，有效降低假阳性率。

### 2.4 Seed 数据强化

**动机**: 伪标签质量不如真实标注，需要提升标注数据的相对权重。

| 数据类型 | 复制次数 | 有效权重 |
|---------|---------|---------|
| Seed（标注数据） | 3× | ~1.0 |
| 伪标签数据 | 1× | ~0.5 |

**效果**: 等效伪标签权重降至 ~0.17，防止模型过度依赖伪标签噪声。

### 2.8 面试高频问答

**Q1: 为什么需要动态置信度阈值？**
> 固定阈值会导致 AP 高的类别阈值过高而漏掉正确预测，AP 低的类别阈值过低而引入假阳性。动态阈值根据类别 AP 自适应调整：AP 高→低阈值（多保留），AP 低→高阈值（严格筛选）。

**Q2: 翻转一致性的核心思想是什么？**
> 基于视角不变性假设：水平翻转不应改变检测结果。如果原图和翻转图的预测不一致（IoU < 0.6 或类别不同），说明至少有一个是假阳性，通过筛选可以有效提升伪标签质量。

**Q3: 为什么取 min 而不是平均融合置信度？**
> 取 min 是悲观策略，只有两个视图都确信才给高置信度。适用于伪标签质量参差不齐、需要严格控制假阳性率的场景。宁可少标注，不要错误标注。

**Q4: Seed 数据强化为什么有效？**
> 伪标签质量 ≈ 0.5 倍真实标签。通过 3x 复制后，伪标签有效权重降至 ~0.17，模型主要依靠真实标注学习基础能力，伪标签作为补充信息而非主要依赖。

**Q5: 迭代伪标签相比单轮有什么优势？**
> 每轮用更强的模型生成更高质量的伪标签，可以逐步降低阈值挖掘更多困难样本，形成正循环：更强模型 → 更好伪标签 → 更强模型。
