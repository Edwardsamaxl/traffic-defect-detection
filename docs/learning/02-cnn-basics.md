# 02 - CNN 基础知识

> 卷积神经网络（CNN）是计算机视觉的核心模型。本章解释卷积、通道、特征图等核心概念。

## 1. 学习目标

学完本章后，你将理解：
- 卷积核与卷积层的关系
- 卷积如何改变通道数和特征图尺寸
- 通道（Channel）的物理含义
- 激活函数为什么必要
- 常见卷积配置的作用

## 2. 核心内容

### 2.1 通道（Channel）的物理含义

一张 RGB 图像可以表示为 `[B, 3, H, W]`：
- `3` 是通道数，代表 R、G、B 三个颜色通道
- 每个通道是一张单色图

经过卷积层后，通道数变为模型设计者指定的数量：

```
输入: [B, 3, 224, 224]  ← RGB图像
      │
      ▼ Conv(64个卷积核)
输出: [B, 64, 224, 224] ← 64张"特征图"
```

**每个通道是一张特征图**，代表某种特征的响应强度：

| 通道1 | 通道2 | 通道3 | ... | 通道64 |
|-------|-------|-------|-----|-------|
| 边缘响应 | 纹理响应 | 颜色响应 | ... | 某种高级语义 |

### 2.2 卷积如何改变通道数

**卷积核不是 2D 的，而是 4D 的**：`[C_out, C_in, K, K]`

```
输入 [B, 3, H, W]
      │
      ├── 64个卷积核
      ├── 每个卷积核 [3, 3, 3] ← (输入通道3, 空间3x3)
      │
      ▼
每个卷积核产生一个输出通道
64个卷积核 → 输出64个通道

输出: [B, 64, H', W']
```

**关键结论**：卷积核的数量 = 输出通道数

### 2.3 卷积核大小与特征图尺寸

**尺寸计算公式**：

```
H' = floor((H + 2×padding - kernel_size) / stride) + 1
```

| 配置 | 输入 | 计算 | 输出 |
|------|------|------|------|
| stride=1, pad=0, k=3 | 32 | (32+0-3)/1+1=30 | 30 |
| stride=1, pad=1, k=3 | 32 | (32+2-3)/1+1=32 | 32（保尺寸） |
| stride=2, pad=1, k=3 | 32 | (32+2-3)/2+1=16 | 16（减半） |

**常见术语**：
- **stride=1**：逐像素滑动，尺寸基本不变
- **stride=2**：跳步滑动，实现下采样，尺寸减半
- **padding**：在边缘填充，使输出尺寸可控

### 2.4 卷积层 vs 卷积核

| 术语 | 含义 |
|------|------|
| **卷积核 (Kernel/Filter)** | 层里的一个小权重矩阵，如 `[3, 3, 3]` |
| **卷积层 (Conv Layer)** | 由多个卷积核组成的层 |
| **特征图 (Feature Map)** | 卷积核的输出 |

```
卷积层 = 一组卷积核

Conv(64, kernel=3):
  ├── Kernel1 → Feature Map 1
  ├── Kernel2 → Feature Map 2
  └── ...
  └── Kernel64 → Feature Map 64
```

### 2.5 为什么需要激活函数

**卷积本身是线性操作**：

```python
output = input * kernel + bias  # 线性变换
```

**线性操作的局限性**：

```
多层线性操作等价于一层：
  x → Linear → Linear → Linear → 等价于 → x → Linear →

无法拟合非线性模式（如折线、曲线）
```

**激活函数引入非线性**：

```
无激活函数:
  x → Conv → x → Conv → x → ...  ← 无论多少层，等价于一层

有激活函数:
  x → Conv → ReLU → x → Conv → ReLU → x → ...
                                            ↑
                                       非线性！
```

**常见激活函数**：

| 激活函数 | 公式 | 特点 |
|----------|------|------|
| ReLU | f(x) = max(0, x) | 计算快，梯度稳定 |
| Sigmoid | f(x) = 1/(1+e^(-x)) | 输出0~1，梯度易消失 |
| Tanh | f(x) = (e^x-e^(-x))/(e^x+e^(-x)) | 输出-1~1 |

### 2.6 一个完整的卷积块

```python
class ConvBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, 3, padding=1)  # 卷积（线性）
        self.bn = nn.BatchNorm2d(out_ch)  # 批归一化
        self.relu = nn.ReLU()  # 激活函数（非线性！）

    def forward(self, x):
        return self.relu(self.bn(self.conv(x)))
```

**流程**：

```
x → Conv (线性) → BN (线性) → ReLU (非线性) → 输出
```

### 2.7 1x1 卷积的特殊作用

1x1 卷积不在空间上滑动（1x1），而是**跨通道融合信息**：

```
输入 [B, 64, H, W] → 1x1Conv(64→32) → [B, 32, H, W]

每个位置(x,y)上:
  output[b, c, x, y] = Σ( weight[c,k] × input[b, k, x, y] )
                        for k in 64通道

作用：通道间信息交互，而非空间特征提取
```

**CBAM 中 1x1 卷积的作用**：融合 AvgPool 和 MaxPool 的信息，决定每个通道的权重。

## 4. 本章小结

- 通道是特征图的"厚度"，每个通道代表一种特征的响应
- 卷积核数量决定输出通道数，卷积核大小决定感受野
- stride>1 实现下采样，尺寸减半
- 卷积是线性操作，必须通过激活函数引入非线性
- 1x1 卷积用于通道间的信息融合
