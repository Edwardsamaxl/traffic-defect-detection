## 各章撰写要点

### 第3章重点（系统实现）

**3.3 基线模型**
- YOLOv8s配置参数
- 训练策略细节

**3.4 CBAM改进**
- YAML配置文件结构
- 集成位置选择依据
- 通道注意力+空间注意力实现

**3.5 损失函数优化**
- WIoU原理与优势
- 替换CIoU的动机

**3.6 小目标检测层优化**
- P2层引入依据
- 对NEU-DET中小缺陷的针对性优化

**3.7 推理服务系统**
- FastAPI后端：模型加载、推理接口、批量处理
- Vue3前端：图片上传、结果可视化、历史记录
- API设计：RESTful接口、响应格式

### 第4章重点（实验验证）

**4.3-4.5 消融实验**
- 表格形式展示：Baseline → +CBAM → +WIoU → +P2 → 全部
- 指标: P/R/mAP50/mAP50-95
- 各类别AP对比

**4.6 综合对比**
- 与现有论文方法对比
- 工程实用性分析
