3.3 基线模型设计

本研究以YOLOv8s（small尺寸）作为缺陷检测的基线模型，采用640×640输入分辨率、batch size为4进行训练，共训练200个epoch，启用早停机制（patience=50）。

基线模型基于Ultralytics官方的yolov8s.pt预训练权重初始化，使用SGD优化器（momentum=0.937，weight_decay=0.0005），初始学习率lr0=0.01，采用线性学习率衰减策略（lrf=0.01），前3个epoch为预热阶段。损失函数由边界框损失（box）、分类损失（cls）和DFL损失（dfl）三部分加权组成，权重分别为7.5、0.5、1.5。

数据增强方面，训练阶段启用Mosaic增强（比例1.0），通过将四张图像拼接为一张的方式扩充数据多样性，提升模型对不同缺陷尺度和场景的泛化能力。验证阶段每epoch结束后在验证集上评估模型性能，输出Precision、Recall、mAP50等指标用于监控训练效果。
