3.4 CBAM注意力机制改进
钢材表面缺陷的形态差异极大：crazing呈现细长线性结构；patches覆盖区域较大但纹理对比度低；inclusion则表现为局部暗色斑点。YOLOv8s的原版backbone对各通道和空间位置采用平等权重处理，缺乏对细粒度特征的聚焦能力。CBAM将注意力分解为通道注意力与空间注意力两部分，以串行方式嵌入网络卷积块中，以极低的参数量代价换取显著的特征提取能力提升。
3.4.1CBAM模块结构
CBAM包含通道注意力模块（Channel Attention Module, CAM）和空间注意力模块（Spatial Attention Module, SAM）两个子模块，按顺序串联于每个卷积块之后，本文实现了简化版的CBAM以降低训练开销。CBAM结构图如图3-2所示。

通道注意力通过全局平均池化将C×H×W的特征图压缩为C×1×1的通道描述子，捕获全局上下文信息。该描述子经1×1卷积映射为同维度向量，再经Sigmoid归一化为各通道的注意力权重（取值范围[0,1]），与原始特征逐通道相乘，完成通道维度的校准。本实现相较原始CBAM论文[1]中的双池化+降维比r=16结构进行了简化：去除全局最大池化支路，并移除中间降维层（1×1卷积直接做C→C映射，不压缩维度）。消融实验结果表明（详见4.3节），原始论文中的降维压缩策略在NEU-DET数据集上反而导致性能下降，简化版通道注意力在降低计算开销的同时取得了更优的检测精度。

空间注意力在通道注意力输出上操作：首先沿通道维分别执行全局平均池化与全局最大池化，将两者结果拼接为2通道图；再经7×7卷积核进行空间上下文编码，随后Sigmoid归一化得到空间注意力权重，与通道校准后的特征逐像素相乘，完成空间维度的聚焦。

3.4.2CBAM集成位置选择
在YOLOv8s backbone中，特征图经多次降采样后形成P2/4（160×160，stride=4）、P3/8（80×80，stride=8）、P4/16（40×40，stride=16）和P5/32（20×20，stride=32）四个主阶段，随后送入PANet进行多尺度特征融合。将CBAM插入不同降采样阶段之后，对最终检测性能的影响存在显著差异。

P2/4阶段的特征图分辨率最高（160×160），保留了最丰富的空间细节信息，理论上最有利于定位细小缺陷（如细裂纹crazing），但该阶段通道数最少（128维），注意力机制的表达能力受限。P3/8阶段（80×80，256维）处于细粒度与语义信息的中和点，是多数缺陷特征表达的主要层级。P4/16阶段（40×40，512维）通道数翻倍，语义信息更加丰富，残差特征已具备较强的类内一致性，但空间精度开始下降。P5/32阶段（20×20，1024维）语义最强但空间信息最为粗糙，对缺陷定位帮助有限。

为系统评估各阶段的贡献，本研究设计了三组消融实验进行位置选择：（1）单位置实验，在P2、P3、P4、P5各阶段独立插入单个CBAM；（2）双位置组合实验，测试P2+P3、P3+P4的组合；（3）全阶段组合（P2+P3+P4），该组合是CBAM原始论文的组合[1]，在backbone的前三个降采样阶段后均插入CBAM。本研究最终采用P2+P3+P4三阶段CBAM集成策略，将CBAM模块分别嵌入backbone第3层（P2/4阶段后）、第6层（P3/8阶段后）和第9层（P4/16阶段后），在通道与空间两个维度协同增强深度特征的判别能力，实验结果详见4.3节。
3.4.3CBAM策略组合
在确定CBAM三阶段（P2+P3+P4）集成策略后，本研究进一步探索CBAM与其他优化策略的组合效果，主要包括CBAM+P2检测层组合和CBAM+BiFPN neck组合两种方案。组合的实验效果详见4.4节。

CBAM+P2检测层组合方案将P2高分辨率检测头与CBAM注意力机制协同使用。P2检测头在neck的上采样路径中引出，经1×1卷积调整通道数后与P3特征图融合，在保持高分辨率的同时引入深层语义信息。

CBAM+BiFPN neck组合方案用BiFPN（双向特征金字塔网络）替换标准的PANet neck。BiFPN通过自顶向下和自底向上的双向路径进行加权特征融合，每层融合过程包含可学习的权重参数，使网络能够自适应调整不同特征层的贡献度。配置文件中，backbone保持CBAM三阶段插入，head部分替换为BiFPN结构。
3.4.4CBAM模块实现
CBAM模块在Ultralytics框架中以自定义模块形式实现，通过继承`nn.Module`定义`ChannelAttention`和`SpatialAttention`两个子模块，再组合为完整的CBAM。模块注册于`ultralytics/nn/modules/__init__.py`，可在YAML配置文件中以`CBAM`名称直接引用。
