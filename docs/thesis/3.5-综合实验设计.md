# 3.5 综合实验设计

## 3.5.1 P2检测层设计

YOLOv8默认采用P3、P4、P5三个检测层进行多尺度特征融合，检测头输出三个尺度Detect(P3, P4, P5)。P2检测头通过引入额外的P2层（下采样4倍，特征图160×160），将检测头输出扩展为四个尺度Detect(P2, P3, P4, P5)，覆盖从细粒度到粗粒度的全尺度目标检测。

P2层来源于backbone第2层C2f模块的输出（128通道），经neck上采样路径与P3、P4、P5特征图融合后送入检测头。配置基于`yolov8-p2.yaml`，P2分支在neck上采样路径中通过Concat操作与backbone P2特征融合。

## 3.5.2 损失函数优化设计

YOLOv8默认使用CIoU损失函数，其在IoU基础上综合考虑三个几何因素：重叠面积、中心点距离和长宽比一致性。其中长宽比惩罚项在处理极端长宽比目标（如细裂纹）时可能导致梯度不稳定。

WIoU v3针对这一问题进行了改进。其核心思想是：训练数据中的低质量样本（离群点）产生的有害梯度会损害模型定位性能。WIoU v3通过构建动态非单调聚焦系数来压制低质量样本的梯度贡献，同时保留其有效梯度信息，引导模型将学习重点聚焦于中等质量的普通样本。实现上，将CIoU替换为WIoU v3，通过修改`ultralytics/utils/loss.py`中的`BboxLoss`类完成。
