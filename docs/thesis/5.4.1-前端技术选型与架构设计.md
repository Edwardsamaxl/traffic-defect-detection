## 5.4.1 前端技术选型与架构设计

### 5.4.1.1 技术选型

系统前端采用原生Vue3框架构建，不依赖构建工具（如Vite或Webpack），通过CDN方式直接引入Vue3、Vue Router和Axios等核心库。这种轻量级架构适合嵌入式部署场景，无需额外的Node.js编译环境，仅需浏览器即可运行。具体技术栈如表5-X所示。

**表5-X 前端技术栈**

| 技术/库 | 版本 | 用途 |
|---------|------|------|
| Vue3 | 3.x (CDN) | 响应式UI框架，组合式API |
| Vue Router | 4.x (CDN) | 前端路由管理，Hash模式 |
| Axios | 1.x (CDN) | HTTP请求库，API通信 |
| Chart.js | 4.x (CDN) | 数据可视化图表 |
| 原生CSS3 | - | 页面样式，无UI组件库 |

选用Vue3的组合式API（Composition API）替代选项式API，使组件逻辑更加紧凑，状态与副作用集中在`setup()`函数内管理。路由采用`createWebHashHistory`模式，避免后端配置URL重写，适配静态文件部署场景。

### 5.4.1.2 整体架构设计

前端采用单页面应用（SPA）架构，所有页面组件内联于单一`index.html`文件中，通过Vue Router根据URL哈希值动态切换视图。整体架构分为三层：

1. **视图层（Views）**：包含登录页、注册页、检测页、历史记录页、仪表盘页和模型管理页六大核心视图。
2. **API层**：基于Axios封装的HTTP客户端，统一处理请求拦截（附加JWT Token）和响应拦截（401自动跳转登录）。
3. **状态层**：利用Vue3的响应式系统（`ref`、`reactive`、`computed`）管理各视图的本地状态，用户认证状态（Token、用户信息）持久化存储于`localStorage`。

### 5.4.1.3 路由配置与导航守卫

路由配置采用Vue Router的`createRouter`定义五个受保护的路由和一个公开路由：

```javascript
const routes = [
  { path: '/login', name: 'login', component: LoginView },
  { path: '/register', name: 'register', component: RegisterView },
  { path: '/detect', name: 'detect', component: DetectView, meta: { requiresAuth: true } },
  { path: '/history', name: 'history', component: HistoryView, meta: { requiresAuth: true } },
  { path: '/dashboard', name: 'dashboard', component: DashboardView, meta: { requiresAuth: true } },
  { path: '/models', name: 'models', component: ModelsView, meta: { requiresAuth: true } },
]
```

导航守卫（`beforeEach`）在路由切换前检查`meta.requiresAuth`标记：若目标页面需要登录且`localStorage`中无有效Token，则强制重定向至登录页；反之，若已登录用户访问登录/注册页，则自动跳转至仪表盘。该机制确保未授权用户无法访问系统核心功能。

### 5.4.1.4 API客户端封装

Axios实例统一配置`baseURL`为`/api`，并设置60秒超时。请求拦截器自动从`localStorage`读取JWT Token并注入`Authorization`请求头；响应拦截器捕获401状态码，清除本地存储的认证信息并跳转登录页，实现全局认证失效处理。

```javascript
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})
api.interceptors.response.use(
  res => res,
  err => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.hash = '#/login'
    }
    return Promise.reject(err)
  }
)
```

### 5.4.1.5 UI设计风格

界面采用黑白极简主义（B&W Light Brutalist Minimal）设计系统，以`#111111`为主色调，`#f5f5f3`为背景色，强调信息层级与功能性。所有样式通过原生CSS内联于`index.html`的`<style>`标签中，未引入Element Plus、Ant Design等第三方UI库，以减小静态资源体积并保证视觉一致性。核心设计规范包括：圆角10px的卡片面板、2px高度的滑块控件、无边框输入框配合聚焦时黑色边框等。
