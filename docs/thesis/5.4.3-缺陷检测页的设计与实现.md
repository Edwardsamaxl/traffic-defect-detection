## 5.4.3 缺陷检测页的设计与实现

### 5.4.3.1 模块功能说明

缺陷检测页是系统的核心功能页面，负责提供钢材表面缺陷的自动识别能力。该模块支持两种检测模式：单图检测（上传单张图片进行推理）和批量检测（上传整个文件夹进行批量推理）。用户可配置检测参数（置信度阈值、IoU阈值、输入尺寸）、选择推理模型，并实时查看检测结果（标注图片、缺陷类别、边界框坐标、置信度分数）。

### 5.4.3.2 页面布局设计

检测页采用左右分栏布局，左侧为配置面板（宽度340px），右侧为结果展示面板（自适应剩余宽度）。页面顶部设置模式切换按钮组（单图检测/批量检测），用户可点击切换检测模式。

左侧配置面板包含四个步骤区域，以步骤编号和标签引导用户操作：

1. **步骤1：配置与上传**
   - 模型选择下拉框：展示系统内置模型和用户上传的自定义模型；
   - 图片/文件夹上传区：单图模式下为点击选择图片，批量模式下为点击选择文件夹；
   - 阈值预设按钮组：平衡（conf=0.25, iou=0.6）、高召回（conf=0.10, iou=0.70）、高精度（conf=0.50, iou=0.50）三种预设，一键切换参数；
   - 置信度与IoU滑块：支持0.01~0.99和0.10~0.95范围内的精细调节；
   - 开始检测按钮：触发推理请求。

2. **步骤2：检测结果**
   - 右侧结果面板展示检测完成后的标注图片和缺陷详情列表。

### 5.4.3.3 模型选择与参数配置

模型选择通过`<select>`元素实现，选项数据通过`axios.get('/api/models')`动态加载。默认选项为"默认模型"（系统内置的CBAM改进模型），用户也可选择已上传的自定义`.pt`模型。选中模型后，下方显示模型文件路径（`model-path`），便于用户确认。

阈值预设功能通过三个按钮实现，点击后自动设置对应的置信度和IoU值。滑块控件采用原生`<input type="range">`自定义样式，轨道高度2px，滑块为14px圆形黑色按钮。滑块值实时显示在标签右侧，精确到小数点后两位。

```javascript
const presets = [
  { id: 'balanced', label: '平衡', conf: 0.25, iou: 0.6 },
  { id: 'high_recall', label: '高召回', conf: 0.1, iou: 0.7 },
  { id: 'high_precision', label: '高精度', conf: 0.5, iou: 0.5 }
]
```

### 5.4.3.4 文件上传交互

单图模式下，上传区为虚线边框的点击区域，内部包含图片图标和提示文字"点击选择图片"。用户点击后触发隐藏的`<input type="file" accept="image/*">`元素，选中文件后前端读取文件对象并显示文件名。批量模式下，上传区使用`webkitdirectory`属性支持文件夹选择，选中后显示文件数量统计。

上传区支持拖拽交互（通过`@dragover`和`@drop`事件监听），用户可将图片直接拖入区域完成选择。

### 5.4.3.5 检测请求与结果展示

点击"开始检测"按钮后，前端构建FormData对象，附加图片文件和查询参数（conf、iou、imgsz、max_det、model_id），通过`axios.post`发送至后端：`/api/detections/predict`（单图）或`/api/detections/batch`（批量）。

请求过程中按钮进入加载状态，显示旋转图标和"检测中..."文字，防止用户重复提交。

**单图检测结果展示：**

检测结果返回后，右侧面板展示以下内容：

1. **标注图片**：通过Base64编码的PNG图片直接渲染`<img>`标签；
2. **结果摘要卡片**：图片尺寸和检测数量，以网格卡片形式呈现；
3. **缺陷列表**：每个检测项包含颜色圆点（按类别ID映射）、缺陷类别名称、边界框坐标（`[x1, y1, x2, y2]`）和置信度百分比。列表支持纵向滚动，最大高度260px。

**批量检测结果展示：**

批量模式展示汇总统计（总文件数、成功数、失败数）和逐文件结果列表。每个文件项显示处理状态（成功/失败）、检测数量和错误信息（如有）。输出目录路径以等宽字体展示，便于用户定位保存的标注图片。

### 5.4.3.6 核心代码说明

检测请求参数构建函数根据当前设置动态生成URL查询字符串，并处理模型ID的类型转换（仅正整数或`proj_`前缀的字符串被传递）：

```javascript
const buildQuery = () => {
  const p = new URLSearchParams({
    conf: settings.conf.toString(),
    iou: settings.iou.toString(),
    imgsz: '640',
    max_det: '300'
  })
  const mid = settings.modelId
  if (mid !== '' && mid !== null) {
    const num = Number(mid)
    if (Number.isInteger(num) && num > 0) {
      p.set('model_id', String(num))
    } else if (String(mid).startsWith('proj_')) {
      p.set('model_id', String(mid))
    }
  }
  return p
}
```

### 5.4.3.7 实现效果

检测页界面清晰，操作流程以步骤化形式引导用户：先配置参数、再上传图片、最后查看结果。滑块和预设按钮提供灵活的参数调节方式，满足不同精度需求的检测场景。单图模式下标注图片与缺陷列表左右联动，用户可直观对照识别结果；批量模式通过汇总卡片快速把握整体检测情况。整体交互流畅，从上传到结果展示的全过程约1~2秒（视图片大小和GPU性能而定）。
