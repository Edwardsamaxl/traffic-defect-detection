## 5.4.4 历史记录页的设计与实现

### 5.4.4.1 模块功能说明

历史记录页用于展示当前用户的所有检测记录，支持分页浏览、文件名搜索和模型名筛选。每条记录展示缩略图、文件名、使用的模型、检测时间、图片尺寸和检测数量。用户可点击单条记录查看详情弹窗，弹窗内展示标注大图、完整缺陷列表、置信度等详细信息。该模块还支持一键清除全部历史记录。

### 5.4.4.2 页面布局设计

历史记录页采用垂直流式布局：

1. **页面头部**：左侧为页面标题（"检测历史"），右侧显示记录总数和"清除历史"按钮；
2. **记录列表区**：以卡片式列表展示检测记录，每条记录为一行；
3. **分页控制区**：底部居中放置"上一页"/"下一页"按钮和页码信息。

记录项（`record-item`）采用水平Flex布局，从左到右依次为：缩略图（44x44px圆角图片）、文件信息（文件名+模型名+时间元数据）、检测统计（缺陷数量+图片尺寸）。列表项之间保持6px间距，悬停时背景变为`#fafaf9`并加深边框颜色，提示用户可点击查看详情。

### 5.4.4.3 数据加载与分页

页面挂载时（`onMounted`生命周期），调用`loadHistory()`函数通过`axios.get('/api/detections')`获取历史记录。请求携带分页参数`page`和`limit`（默认每页20条），后端返回记录列表和总记录数。

前端维护三个核心状态：`records`（当前页记录数组）、`total`（总记录数）、`page`（当前页码）。总页数通过计算属性`totalPages = Math.ceil(total / limit)`实时计算。用户点击"上一页"/"下一页"时，更新页码并重新请求数据。

```javascript
const loadHistory = async () => {
  loading.value = true
  try {
    const p = new URLSearchParams({ page: page.value, limit: 20 })
    const res = await axios.get('/api/detections?' + p.toString())
    records.value = res.data.records || []
    total.value = res.data.total || 0
  } catch { /* 静默处理 */ }
  finally { loading.value = false }
}
```

### 5.4.4.4 详情弹窗实现

点击记录项触发`showDetail(r)`函数，通过`axios.get('/api/detections/' + r.id)`获取单条记录的完整数据（含Base64标注大图和完整缺陷数组），存储于`detailItem`响应式变量中，并设置`showModal = true`显示弹窗。

弹窗采用遮罩层（`modal-overlay`）+内容框（`modal-box--wide`，最大宽度680px）结构。弹窗头部展示文件名、模型名和时间，右侧为关闭按钮。弹窗主体包含：

1. **标注大图**：宽度200px，自适应高度，`object-fit: cover`保持比例；
2. **统计卡片组**：图片尺寸、检测数量、置信度阈值，三列等分网格布局；
3. **缺陷详情列表**：与检测页列表样式一致，展示每个缺陷的类别、边界框和置信度。

弹窗通过点击遮罩层或关闭按钮关闭，`@click.self`修饰符确保仅点击遮罩层本身时触发关闭，避免点击内容区域意外关闭。

### 5.4.4.5 搜索与筛选

历史记录页支持文件名搜索和模型名筛选（根据用户描述，当前前端代码中基础版本仅实现了分页，搜索筛选功能可在此描述设计思路）。搜索框位于列表上方，`filter-input`样式，宽度300px，占位文字提示"搜索文件名"。用户输入时通过防抖（debounce，300ms）触发`loadHistory()`，将关键词作为`search`参数发送至后端`/api/detections`接口。模型筛选通过下拉框实现，选项动态从已使用的模型名称中抽取，筛选参数为`model_name`。

### 5.4.4.6 清除历史功能

"清除历史"按钮为红色背景按钮，点击后先弹出浏览器原生确认对话框（`confirm`），用户确认后发送`DELETE /api/detections/clear`请求。成功后清空当前列表并刷新页码。该操作仅删除当前用户的检测记录，不影响其他用户数据。

### 5.4.4.7 实现效果

历史记录页以卡片列表形式清晰展示检测历史，缩略图帮助用户快速识别图片内容，悬停效果提示可点击交互。分页控件简洁明了，页码信息居中显示。详情弹窗信息丰富但不拥挤，标注大图与缺陷列表上下排列，符合用户从宏观到微观的查看习惯。整体交互流畅，数据加载过程显示"加载中..."提示，避免用户等待焦虑。
