## 5.4.5 仪表盘页的设计与实现

### 5.4.5.1 模块功能说明

仪表盘页是系统的数据概览中心，为用户提供检测行为的宏观统计视图。该模块调用`/api/dashboard/stats`接口获取统计数据，展示三项核心指标（总检测次数、今日检测、日均检测），并通过Chart.js图表可视化过去7天的检测趋势和缺陷类别分布。底部还展示最近5条检测记录的快速入口。

### 5.4.5.2 页面布局设计

仪表盘页采用垂直分层布局：

1. **页面头部**：左侧标题"数据统计"，右侧标注"最近7天"提示统计时间范围；
2. **统计指标行（stats-row）**：三列等分网格，每张统计卡片（`stat-card`）展示一个核心指标；
3. **图表行（charts-row）**：两列等分网格，左侧折线图展示每日检测趋势，右侧环形图展示缺陷类型分布；
4. **最近记录面板（recent-panel）**：展示最近5条检测记录列表。

统计卡片采用白色背景、圆角10px、边框1px的极简卡片设计。指标数值使用36px大字号、800字重突出显示，标签使用12px小字号、灰色、全大写字母，形成强烈的视觉层级对比。

### 5.4.5.3 统计数据加载

页面挂载时并行发起两个请求：

1. `axios.get('/api/dashboard/stats')`获取统计数据，包括`total_detections`（累计检测数）、`detections_today`（今日检测数）、`by_day`（近7天每日统计数组）、`by_class`（缺陷类别分布数组）；
2. `axios.get('/api/detections?limit=5')`获取最近5条检测记录。

统计数据存储于`stats`响应式对象中，日均检测通过计算属性实时计算：

```javascript
const avgPerDay = computed(() => {
  const days = stats.value.by_day?.length || 1
  return Math.round(stats.value.total_detections / days)
})
```

### 5.4.5.4 折线图：每日检测趋势

折线图基于Chart.js的Line类型实现，横轴为日期（格式化为"M/D"），纵轴为检测次数。图表样式配置如下：

- 折线颜色：`#111111`纯黑色，线宽2px；
- 数据点：半径5px，白色填充，黑色边框，悬停时半径扩大至7px；
- 曲线平滑度：`tension: 0.35`，呈现自然曲线过渡；
- 纵轴网格线：浅灰色`#e5e5e3`，横轴无网格线；
- 提示框（Tooltip）：黑色背景、白色文字，圆角6px，显示完整日期和检测次数。

```javascript
new Chart(ctx, {
  type: 'line',
  data: {
    labels: data.map(d => {
      const [year, month, day] = d.date.split(' ')[0].split('-')
      return `${parseInt(month)}/${parseInt(day)}`
    }),
    datasets: [{
      label: '检测数',
      data: data.map(d => d.count),
      borderColor: '#111111',
      borderWidth: 2,
      backgroundColor: 'transparent',
      tension: 0.35,
      pointRadius: 5,
      pointHoverRadius: 7,
      pointBackgroundColor: '#ffffff',
      pointBorderColor: '#111111',
      pointBorderWidth: 2,
    }]
  },
  options: {
    responsive: true,
    plugins: { legend: { display: false } },
    scales: {
      x: { ticks: { color: '#6b7280', font: { size: 11 } }, grid: { display: false } },
      y: { ticks: { color: '#6b7280' }, grid: { color: '#e5e5e3' }, beginAtZero: true }
    }
  }
})
```

### 5.4.5.5 环形图：缺陷类型分布

缺陷类型分布采用Doughnut（环形图）类型，每种缺陷类别分配一个预设颜色（红、橙、黄、绿、青、蓝、紫、粉等10色循环）。图例置于右侧，标签颜色为灰色，字号11px，无边框。

```javascript
new Chart(ctx, {
  type: 'doughnut',
  data: {
    labels: data.map(d => d.class_name),
    datasets: [{
      data: data.map(d => d.count),
      backgroundColor: ['#ef4444','#f97316','#eab308','#22c55e','#14b8a6',
                        '#3b82f6','#8b5cf6','#ec4899','#f43f5e','#6366f1'],
      borderWidth: 0
    }]
  },
  options: {
    responsive: true,
    plugins: {
      legend: { position: 'right', labels: { color: '#6b7280', boxWidth: 10 } }
    }
  }
})
```

### 5.4.5.6 最近检测记录列表

最近记录列表展示最近5条检测记录，每条记录包含文件名、模型名、时间和检测数量。布局与历史记录页一致，但不支持点击详情，仅作为快速概览入口。若用户无检测记录，显示空状态（"暂无数据"）。

### 5.4.5.7 实现效果

仪表盘页信息密度适中，统计指标以大字号突出核心数据，折线图和环形图以黑白为主色调，与系统整体风格统一。Chart.js图表响应式适配容器大小，在不同屏幕宽度下均能正常渲染。数据加载时先显示"加载中..."提示，图表在数据返回后延迟80ms渲染，确保DOM已就绪。整体页面为用户提供了一目了然的数据概览，帮助用户掌握检测行为趋势和缺陷分布特征。
