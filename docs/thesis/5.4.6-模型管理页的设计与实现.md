## 5.4.6 模型管理页的设计与实现

### 5.4.6.1 模块功能说明

模型管理页负责展示系统内置模型与用户上传的自定义模型列表，支持模型文件上传（仅`.pt`格式）和自定义模型删除操作。上传成功的模型自动加入检测页的模型选择下拉框，用户可在检测时自由切换。内置模型（如系统预装的CBAM改进模型）不可删除，仅用户自行上传的模型可执行删除操作。

### 5.4.6.2 页面布局设计

模型管理页采用垂直流式布局：

1. **页面头部**：左侧标题"模型"，右侧"上传模型"按钮；
2. **模型列表区**：以卡片式列表展示所有可用模型，每条模型为一行；
3. **上传弹窗**：模态对话框，包含文件选择区和上传按钮。

模型卡片（`model-card`）采用水平Flex布局，左侧为模型图标（36x36px圆角方框内嵌神经网络SVG图标）、模型信息（名称+路径+上传时间），右侧为删除按钮（仅对当前用户上传的模型显示）。卡片之间保持8px间距，悬停时边框颜色加深，提供视觉反馈。

### 5.4.6.3 模型列表加载

页面挂载时调用`loadModels()`函数，通过`axios.get('/api/models')`获取模型列表。后端返回的数据包含模型ID、名称、路径、是否内置标志、上传者ID和上传时间。前端将数据存储于`models`响应式数组中，并通过`v-for`渲染列表。

每个模型项的删除按钮通过条件渲染控制显示：`v-if="m.uploaded_by === currentUserId"`。`currentUserId`从`localStorage`中的用户信息解析获得，确保用户仅能删除自己上传的模型，防止误删系统内置模型或其他用户模型。

### 5.4.6.4 模型上传实现

点击"上传模型"按钮触发`showUploadModal = true`，显示上传弹窗。弹窗包含：

1. **文件选择区**：虚线边框的点击区域，内部提示"点击选择 .pt 模型文件"；
2. **已选文件名**：选中文件后显示文件名；
3. **错误提示**：上传失败时显示红色错误信息；
4. **上传按钮**：禁用状态（未选文件或上传中），加载时显示旋转动画。

文件选择通过隐藏的`<input type="file" accept=".pt">`实现，仅允许选择`.pt`扩展名的文件。选中文件后触发`onFileSelected()`，将文件对象存入`uploadFile`变量。

点击"开始上传"后，前端构建`FormData`对象，附加文件，发送至`POST /api/models/upload`。后端校验文件类型（`.pt`后缀）、文件非空、路径安全性（防止目录遍历攻击），保存文件至`experiments/uploaded_models/`目录，并将记录写入MySQL数据库。上传成功后，弹窗关闭，列表自动刷新，新模型即刻出现在检测页的下拉框中。

```javascript
const uploadModel = async () => {
  if (!uploadFile.value) return
  uploading.value = true
  uploadError.value = ''
  try {
    const fd = new FormData()
    fd.append('file', uploadFile.value)
    await axios.post('/api/models/upload', fd)
    showUploadModal.value = false
    uploadFile.value = null
    await loadModels()
  } catch (e) {
    uploadError.value = e.response?.data?.detail || '上传失败'
  } finally {
    uploading.value = false
  }
}
```

### 5.4.6.5 模型删除实现

点击模型卡片右侧的删除按钮（红色垃圾桶图标），首先弹出浏览器确认对话框。用户确认后，发送`DELETE /api/models/{id}`请求。后端校验：仅允许删除`uploaded_by`等于当前用户ID的模型，内置模型或他人模型返回403禁止删除。删除成功后，从文件系统中移除模型文件，并从数据库删除记录，前端列表自动刷新。

```javascript
const deleteModel = async (m) => {
  if (!confirm('确定删除该模型？')) return
  try {
    await axios.delete('/api/models/' + m.id)
    await loadModels()
  } catch (e) {
    alert(e.response?.data?.detail || '删除失败')
  }
}
```

### 5.4.6.6 权限控制

模型管理的权限控制分为两层：

1. **前端控制**：删除按钮仅对`uploaded_by === currentUserId`的模型显示，内置模型不展示删除按钮；
2. **后端控制**：删除接口校验Token对应的用户ID与模型的`uploaded_by`字段是否一致，不一致返回403错误，防止前端绕过验证的恶意删除请求。

该双层校验机制确保了权限控制的安全性，即使前端代码被篡改，后端仍然拒绝越权操作。

### 5.4.6.7 实现效果

模型管理页界面简洁，模型卡片信息清晰（名称、路径、上传时间一目了然）。上传弹窗操作直观，文件类型限制和错误提示降低了用户误操作的概率。删除操作需要二次确认，避免误删。上传成功的模型即时同步至检测页，用户无需刷新整个页面即可使用新模型。整体交互符合用户直觉，权限控制安全可靠。
