# Abstract

With the rapid development of deep learning technology, object detection algorithms based on convolutional neural networks have achieved remarkable progress in the field of industrial defect detection. However, surface defects on traffic components are diverse in type and varied in morphology, making the improvement of detection accuracy still a key focus and challenge in current research. In this paper, we address the traffic component defect detection task and propose a YOLOv8s detection model with an improved CBAM (Convolutional Block Attention Module) attention mechanism, along with a complete inference service system.

In terms of model improvement, this paper selects the lightweight YOLOv8s as the baseline detection network and innovatively introduces the CBAM attention mechanism for optimization. CBAM consists of channel attention module and spatial attention module connected in series, which can adaptively enhance the feature expression of defect regions in the feature map while effectively suppressing background noise interference. Experimental results on the NEU-DET steel surface defect dataset demonstrate that the improved model achieves significant performance gains: Precision improved from 70.0% to 76.0%, and mAP@0.5 improved from 0.773 to 0.787, representing improvements of 6.0% and 1.4 percentage points respectively compared to the baseline model.

In terms of system implementation, this paper designs and implements a complete front-end and back-end inference service system based on the FastAPI framework. The back-end service is responsible for core functions including model loading, single-image inference, batch inference, and result storage. The front-end uses the Vue3 framework to build a user interaction interface, providing functionalities such as image upload, detection result visualization, and historical record queries. The system has good scalability and usability, meeting the defect detection requirements in practical industrial scenarios.

This paper also conducts extensive ablation experiments to verify the effectiveness of the proposed improvement. The experiments validate the effectiveness of CBAM through ablation studies. Additionally, this paper explores the applicability of optimization strategies such as WIoU loss function, P2 small object detection layer, and Focal Loss on the NEU-DET dataset. Experimental results prove that the CBAM improvement is the optimal strategy for enhancing detection performance on this dataset, while other optimization strategies fail to improve mAP on the NEU-DET dataset.

In summary, the CBAM improvement scheme proposed in this paper achieves effective accuracy improvements in traffic component defect detection tasks, and the complete inference service system also provides good technical support for subsequent model deployment and applications.

**Keywords**: Object Detection; YOLOv8; CBAM Attention Mechanism; Defect Detection; Deep Learning
