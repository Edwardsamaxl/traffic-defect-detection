# 第1章 绪论

## 1.1 研究背景与意义

在现代工业制造体系中，产品质量是企业的生命线，而缺陷检测作为质量控制的关键环节，直接关系到产品的可靠性与安全性。工业缺陷检测旨在对生产过程中的产品进行自动化巡检，及时发现并定位各类表面缺陷，如裂纹、划痕、凹坑、夹杂等，从而保障产品质量，减少因缺陷产品流入市场而带来的经济损失与安全隐患。随着制造业向智能化、自动化方向快速发展，传统的基于人工目检的缺陷检测方式已难以满足现代工业生产对效率与精度的双重要求[1]。

钢材作为重要的基础工业材料，广泛应用于建筑、汽车、船舶、机械装备等国民经济关键领域。钢材表面缺陷不仅影响产品的外观与使用寿命，严重时甚至会引发安全事故，危及人员生命财产安全。因此，高效、准确地检测钢材表面缺陷具有重要的工程价值与经济意义[2]。然而，钢材表面缺陷检测面临着诸多挑战：缺陷种类繁多、形态各异、尺度变化大；部分缺陷如微裂纹、轻微划痕等特征不明显，易被噪声干扰；工业生产环境复杂，光照条件、背景纹理等因素都会影响检测效果[1][3]。

近年来，深度学习技术的快速发展为工业缺陷检测带来了新的解决方案。以卷积神经网络为代表的深度学习方法能够自动学习图像特征表示，克服了传统机器学习方法依赖人工设计特征的局限性，在图像分类、目标检测、语义分割等视觉任务中取得了显著成效[3]。其中，YOLO（You Only Look Once）系列目标检测算法因其兼顾检测精度与推理速度的优异性能，成为工业缺陷检测领域的研究热点[2][4]。

尽管现有基于深度学习的缺陷检测方法已取得较大进展，但在实际应用中仍存在一些问题与挑战。首先，部分检测模型结构复杂、参数量大，难以部署到资源受限的工业检测设备上，面临着精度与速度之间的权衡问题[2]。其次，缺陷检测任务中存在大量小目标缺陷，现有检测器对小目标的召回率较低，容易出现漏检现象[3]。此外，缺陷特征与背景特征之间的区分度不高，模型难以有效捕捉细粒度缺陷特征，影响了检测精度的进一步提升。针对上述问题，本研究聚焦于基于YOLOv8与注意力机制的钢材表面缺陷检测方法，旨在通过模型轻量化设计、小目标检测层优化以及注意力机制引入等手段，提升检测模型的精度与实用性。

本研究的意义主要体现在以下几个方面：（1）通过CBAM注意力机制的引入，增强模型对缺陷特征的关注能力，提升检测精度；（2）通过小目标检测层优化，改善模型对小尺度缺陷的检测性能；（3）通过损失函数优化，提升模型在复杂场景下的泛化能力；（4）设计并实现一套完整的缺陷检测推理服务系统，为工业应用提供便捷的部署方案。

## 1.2 国内外研究现状

### 1.2.1 工业缺陷检测研究现状

工业缺陷检测一直是计算机视觉与机器视觉领域的研究热点。传统的工业缺陷检测方法主要基于机器视觉技术，通过图像处理算法（如边缘检测、纹理分析、阈值分割等）对产品表面进行分析[1]。这些方法在特定场景下能够取得一定的检测效果，但难以应对复杂多变的工业环境，且泛化能力有限。

随着深度学习技术的发展，基于卷积神经网络的缺陷检测方法逐渐成为主流。Cheng等人[1]对工业缺陷检测技术进行了全面综述，系统分析了闭集检测与开集检测两大类方法的研究进展，指出深度学习显著提升了缺陷检测的精度与鲁棒性，但数据集标注成本高、缺陷样本稀缺、细粒度特征难以捕捉等问题仍需解决。Gao等人[3]针对钢材表面缺陷分类任务，提出基于YOLOv5的改进方法YOLOv5-KBS，通过引入注意力机制与加权双向特征金字塔网络，有效提升了缺陷检测精度。Chen等人[2]提出基于YOLOv9s的轻量化检测框架，引入C3Ghost模块、SCConv模块与CARAFE上采样算子，在保持较高检测精度的同时降低了模型参数量与计算复杂度。

在数据集方面，NEU-DET是东北大学发布的钢材表面缺陷检测数据集，包含六类典型缺陷（裂纹、夹杂、划痕、凹坑、氧化皮、轧制缺陷），已成为钢材缺陷检测领域广泛使用的基准数据集[3]。该数据集涵盖了工业生产中常见的多类缺陷样本，为算法性能评估提供了统一的测试平台。

### 1.2.2 YOLO目标检测算法研究现状

YOLO系列算法自2016年提出以来，经历了多次重要迭代，从YOLOv1到YOLO11，每个版本都在网络架构、特征融合、损失函数等方面进行了改进[4]。YOLO系列的核心思想是将目标检测问题转化为单阶段回归问题，通过骨干网络提取特征后直接预测目标类别与位置，实现了检测速度与精度的良好平衡。

YOLOv8是Ultralytics公司于2023年发布的版本，引入了无锚框（anchor-free）检测机制，简化了网络结构，降低了超参数依赖性[4]。YOLOv8提供了n、s、m、l、x五种规模的模型，兼顾了从移动端到服务器端的多场景部署需求。YOLOv9则进一步引入了可编程梯度信息（PGI）与广义高效层聚合网络（GELAN），在保持实时性的同时提升了检测精度。YOLOv10进一步实现了无需非极大值抑制（NMS-free）的后处理方式，简化了部署流程。YOLO11作为最新版本，在架构上进行了多项优化，继续保持着YOLO系列的高性能表现[4]。

Hidayatullah等人[4]对YOLOv8至YOLO11的架构进行了深入对比分析，指出尽管各版本在特征提取与处理方式上有所差异，但核心的特征金字塔与检测头结构保持一致，这种模块化设计使得YOLO系列具有良好的可扩展性与易用性。

### 1.2.3 注意力机制在缺陷检测中的应用

注意力机制是深度学习领域的重要技术之一，其核心思想是让模型能够自适应地关注输入数据中的关键信息，抑制无关背景干扰。在缺陷检测任务中，注意力机制可以帮助模型更好地捕捉缺陷区域的特征，提升检测精度。

CBAM（Convolutional Block Attention Module）是最常用的注意力模块之一，由通道注意力（Channel Attention Module）与空间注意力（Spatial Attention Module）两部分组成。通道注意力通过学习得到各通道的重要性权重，强化重要特征通道的响应；空间注意力则关注空间位置的重要性，增强缺陷区域的特征表达。CBAM以其轻量化的设计与显著的效果提升，在目标检测与图像分割任务中得到了广泛应用。

研究表明，将CBAM嵌入到YOLO系列网络的特征融合路径中，可以有效提升模型对缺陷特征的提取能力[3]。具体而言，通道注意力能够帮助模型筛选出与缺陷相关的特征通道，过滤掉背景噪声；空间注意力则引导模型关注缺陷所在的空间区域，提升定位精度。Gao等人[3]在YOLOv5-KBS中引入注意力机制后，检测精度提升了4.2%，验证了注意力机制在缺陷检测中的有效性。

## 1.3 研究目标与主要工作

本研究以钢材表面缺陷检测为研究对象，基于YOLOv8算法框架，围绕提升检测精度与实用性这一核心目标，开展以下研究工作：

（1）基线模型构建：以YOLOv8s作为基线模型，在NEU-DET数据集上进行训练与评估，分析现有模型在钢材缺陷检测任务上的表现及其存在的问题。

（2）CBAM注意力机制改进：将CBAM模块嵌入到YOLOv8的特征融合网络中，增强模型对缺陷特征的提取能力。通过对比不同嵌入位置的效果，确定最优的CBAM集成方案。

（3）损失函数优化：采用WIoU（Wise-IoU）损失函数替代原生CIoU损失函数，降低简单样本对模型训练的贡献，提升模型在复杂场景下的泛化能力。

（4）小目标检测层优化：引入P2检测层，增强模型对小尺度缺陷的检测能力。通过在原有P3、P4、P5层基础上增加高分辨率的P2层，提升小目标缺陷的召回率。

（5）推理服务系统开发：基于FastAPI框架开发后端推理服务，基于Vue3开发前端交互界面，实现图片上传、缺陷检测、结果可视化等功能，为工业应用提供便捷的部署方案。

## 1.4 论文结构安排

本论文共分为五章，各章内容安排如下：

第1章绪论，阐述研究背景与意义，分析工业缺陷检测、YOLO目标检测算法及注意力机制在缺陷检测中应用的国内外研究现状，明确研究目标与主要工作，给出论文结构安排。

第2章相关理论与技术基础，介绍YOLOv8目标检测算法的网络架构与检测原理，阐述CBAM注意力机制的结构与工作原理，分析数据增强策略的基本方法。

第3章系统设计与实现，定义钢材表面缺陷检测问题，给出NEU-DET数据集的介绍，详细阐述基线模型设计、CBAM注意力机制改进、损失函数优化、小目标检测层优化等关键技术，以及推理服务系统的设计与实现。

第4章实验与分析，介绍实验环境与配置，给出评价指标体系，通过消融实验验证各改进措施的有效性，通过综合对比实验与现有方法进行比较，分析系统性能。

第5章总结与展望，总结本研究的主要工作与贡献，展望未来研究方向。
