# 第1章 绪论

## 1.1 研究背景与意义

在现代工业制造体系中，产品质量是企业生存与发展的核心要素，而缺陷检测作为质量控制的关键环节，直接关系到产品的可靠性、安全性以及企业的经济效益。工业缺陷检测旨在对生产过程中的产品进行自动化巡检，及时发现并定位各类表面缺陷，如裂纹、划痕、凹坑、夹杂、氧化皮等，从而保障产品质量，减少因缺陷产品流入市场而带来的经济损失与安全隐患。随着制造业向智能化、自动化方向快速转型，传统的基于人工目检的缺陷检测方式已难以满足现代工业生产对检测效率与精度的双重要求[1]。

钢材作为最重要的基础工业材料之一，广泛应用于建筑、汽车、船舶、机械装备、能源设施等国民经济关键领域。钢材表面缺陷的形成贯穿于冶炼、轧制、冷却等整个生产流程，缺陷类型繁多、形态各异。Cheng等[1]指出，钢材表面常见缺陷主要包括裂纹（Cracks）、夹杂（Inclusions）、划痕（Scratches）、凹坑（Patches）、氧化皮（Scale）以及轧制缺陷（Rolling marks）等六类。钢材表面缺陷不仅影响产品的外观与力学性能，严重时甚至会引发结构失效，危及人员生命财产安全。因此，高效、准确地实现钢材表面缺陷检测具有重要的工程价值与经济意义[2]。

然而，钢材表面缺陷检测在实践中面临着诸多挑战[1]：第一，缺陷种类繁多且形态差异显著，从面积较大的表面斑痕到细小的微裂纹，尺度跨度大；第二，部分缺陷如微裂纹、轻微划痕等特征不明显，易被噪声干扰，与正常背景纹理混杂难以区分；第三，工业生产环境复杂多变，光照条件不均匀、背景纹理复杂、图像采集质量不稳定等因素都会影响检测效果；第四，缺陷样本在实际生产中天然稀缺，正负样本严重不平衡，给基于数据驱动的深度学习方法带来了训练难度；第五，工业检测对实时性有较高要求，需要在检测精度与推理速度之间找到合理平衡。这些挑战使得钢材表面缺陷检测成为一个兼具科研价值与工业应用意义的难题。

近年来，深度学习技术的快速发展为工业缺陷检测带来了突破性解决方案。以卷积神经网络为代表的深度学习方法能够自动学习图像的层次化特征表示，克服了传统机器学习方法依赖人工设计特征的局限性，在图像分类、目标检测、语义分割等视觉任务中取得了显著成效[2][3]。Cheng等[1]对工业缺陷检测技术进行了全面综述，将现有方法划分为闭集检测（Closed-set detection）与开集检测（Open-set detection）两大类，其中闭集检测假设所有缺陷类型在训练时已知，开集检测则关注对未知缺陷类型的鲁棒识别能力。研究表明，深度学习方法在闭集检测场景下已取得优异性能，但在处理缺陷形态变异大、背景干扰强等复杂情况时仍存在不足。

在众多深度学习目标检测算法中，YOLO（You Only Look Once）系列因其兼顾检测精度与推理速度的优异表现，成为工业缺陷检测领域最具竞争力的主流方法[3][4]。YOLO系列的核心设计思想是将目标检测问题转化为单阶段回归问题，通过骨干网络（Backbone）提取图像特征后直接预测目标类别与边界框位置，无需额外区域提议阶段，从而实现了检测速度与精度的良好平衡[4]。Hidayatullah等[4]指出，从YOLOv8到YOLO11，YOLO系列经历了anchor-free机制革新、无NMS后处理设计以及多尺度特征融合策略优化等重要技术演进，在保持实时检测能力的同时持续提升检测精度。

针对钢材表面缺陷检测任务，Chen等[2]提出基于YOLOv9s的轻量化检测框架，引入C3Ghost模块、SCConv空间通道重构卷积与CARAFE上采样算子，在保持较高检测精度的同时显著降低了模型参数量与计算复杂度。Gao等[3]针对钢材表面缺陷分类任务，提出基于改进YOLOv5的分类方法YOLOv5-KBS，通过引入注意力机制与加权双向特征金字塔网络，有效提升了缺陷分类精度。这些研究验证了基于YOLO框架进行钢材表面缺陷检测的可行性与有效性。

尽管现有基于深度学习的缺陷检测方法已取得较大进展，但Hidayatullah等[4]的架构分析表明，在实际工业应用中仍存在一些亟待解决的问题。首先，部分检测模型结构复杂、参数量大，难以部署到资源受限的工业检测设备上，在精度与速度之间面临两难抉择[2]。其次，钢材表面缺陷中包含大量小尺度缺陷（如微裂纹、细小划痕等），现有检测器对小目标的召回率较低，容易出现漏检现象[1]。此外，缺陷特征与背景纹理之间的区分度不高，模型难以有效捕捉细粒度缺陷特征，在复杂背景下误检率较高[1][3]。

针对上述问题，本研究聚焦于基于YOLOv8与注意力机制的钢材表面缺陷检测方法，旨在通过模型轻量化设计、小目标检测层优化以及注意力机制引入等手段，系统性地提升检测模型在钢材表面缺陷检测任务上的精度与实用性。具体而言，本研究的主要改进包括：以YOLOv8s作为基线模型，通过CBAM（Convolutional Block Attention Module）注意力机制增强模型对缺陷特征的关注能力；采用WIoU（Wise-IoU）损失函数优化训练过程，降低简单样本的主导作用；引入P2高分辨率检测层提升小尺度缺陷的召回率。整体研究为工业钢材表面缺陷的智能化检测提供了兼具精度与实用性的技术方案。

## 1.2 国内外研究现状

### 1.2.1 工业缺陷检测研究现状

工业缺陷检测是机器视觉与计算机视觉领域的研究热点，其目标是对生产线上产品表面进行快速、准确的自动化检测。Cheng等[1]对工业缺陷检测技术进行了系统性综述，将该领域的发展历程划分为传统机器视觉阶段与深度学习阶段，并指出两个阶段的核心差异在于特征提取方式：传统方法依赖人工设计的图像处理算法（如边缘检测、纹理分析、阈值分割、形态学运算等）提取缺陷特征，在特定约束场景下能够取得一定效果，但难以应对复杂多变的工业环境，泛化能力有限。

进入深度学习阶段，以卷积神经网络为代表的特征自学习方法显著提升了缺陷检测的精度与鲁棒性。Cheng等[1]将工业缺陷检测方法进一步细分为基于检测（Detection-based）、基于分割（Segmentation-based）、基于恢复（Restoration-based）以及基于自监督（Self-supervised-based）四大类技术路线。其中，基于检测的方法以目标检测框架为基础，直接输出缺陷的类别与位置信息，代表性工作包括针对钢材表面缺陷检测的YOLO系列改进算法[2][3]；基于分割的方法以语义分割或实例分割网络为基础，提供像素级的缺陷定位能力，但推理速度相对较慢；基于恢复的方法通过比较正常样本与待测样本的差异来识别缺陷，适用于异常检测场景；基于自监督的方法则利用大量无标注数据进行预训练，再通过少量标注样本微调，在缺陷样本稀缺的场景下具有独特优势。

在数据集方面，NEU-DET（ Northeastern University Defect Detection Dataset）是由东北大学发布的钢材表面缺陷检测数据集，包含六类典型缺陷（裂纹、夹杂、划痕、凹坑、氧化皮、轧制缺陷），每类缺陷包含数百张标注图像，已成为钢材缺陷检测领域广泛使用的基准数据集[2][3]。该数据集涵盖了工业生产中常见的多类缺陷样本，且缺陷形态多样、尺度变化大，为算法性能评估提供了统一的测试平台。然而，Cheng等[1]同时指出，工业缺陷检测领域普遍面临数据标注成本高、缺陷样本稀缺、缺陷类别分布不均衡等数据层面的挑战。

### 1.2.2 YOLO目标检测算法研究现状

YOLO系列算法自2016年由Redmon等提出以来，经历了多次重要迭代，从YOLOv1到YOLO11，每个版本都在网络架构、特征融合机制、损失函数设计等方面进行了系统性改进[4]。YOLO系列的核心思想是将目标检测问题转化为单阶段回归问题，通过骨干网络提取特征后直接预测目标类别与位置坐标，实现了检测速度与精度的良好平衡[4]。

YOLOv8于2023年由Ultralytics公司发布，引入了无锚框（anchor-free）检测机制，简化了网络结构，降低了对预定义锚框的依赖性，提高了超参数的鲁棒性[4]。YOLOv8提供了n（nano）、s（small）、m（medium）、l（large）、x（extra-large）五种规模的模型架构，从移动端嵌入式设备到服务器端高性能推理均有覆盖。Hidayatullah等[4]对YOLOv8至YOLO11的架构进行了深入对比分析，指出YOLOv8采用了CSP（Cross Stage Partial）骨干网络结合PANet（Path Aggregation Network）特征金字塔的结构，检测头采用解耦头（Decoupled Head）设计，将分类分支与定位分支分离处理，这一架构在后续版本中得到了延续。

YOLOv9于2024年发布，进一步引入了可编程梯度信息（Programmable Gradient Information, PGI）与广义高效层聚合网络（Generalized Efficient Layer Aggregation Network, GELAN），通过辅助可逆分支缓解深层网络中的梯度消失问题，在保持实时性的同时进一步提升了检测精度[4]。YOLOv10则实现了无需非极大值抑制（Non-Maximum Suppression-free, NMS-free）的端到端检测方式，简化了后处理流程，降低了推理延迟。YOLO11作为截至目前最新的版本，在骨干网络结构、特征融合路径以及检测头设计上进行了多项优化，继续保持着YOLO系列在实时目标检测领域的领先地位[4]。

在工业缺陷检测领域，YOLO系列算法因其优异的综合性能成为主流选择。Chen等[2]针对钢材表面缺陷检测任务，提出基于YOLOv9s的轻量化改进方案，通过引入C3Ghost模块降低参数量，SCConv模块重构空间与通道特征表达，CARAFE上采样算子增强特征表达能力，在NEU-DET数据集上取得了较高的检测精度，同时显著降低了模型计算复杂度。Gao等[3]则基于YOLOv5进行改进，构建了YOLOv5-KBS模型，引入注意力机制强化缺陷特征提取能力。这些研究表明，YOLO框架在工业缺陷检测任务上具有显著的适用性与扩展潜力。

### 1.2.3 注意力机制在缺陷检测中的应用

注意力机制是深度学习领域的重要技术之一，其核心思想是让模型能够自适应地关注输入数据中的关键信息，抑制无关背景干扰。Cheng等[1]指出，注意力机制在缺陷检测中的引入有效缓解了细粒度缺陷特征难以捕捉、背景干扰难以排除等问题，已成为提升检测精度的重要技术手段。

CBAM（Convolutional Block Attention Module）是由Woo等提出的经典注意力模块，由通道注意力（Channel Attention Module）与空间注意力（Spatial Attention Module）两部分串联组成。通道注意力通过全局池化与多层感知机学习各通道的重要性权重，强化重要特征通道的响应；空间注意力则通过空间维度的压缩与卷积操作，生成空间注意力图，增强缺陷区域的空间响应而抑制背景区域。CBAM以其轻量化设计与即插即用的便利性，在目标检测与图像分割任务中得到了广泛应用。

在YOLO网络中嵌入CBAM注意力模块的典型做法是将CBAM放置在骨干网络与特征金字塔网络的连接处或特征融合路径的关键节点处。Gao等[3]的研究表明，将CBAM嵌入到YOLOv5的特征融合路径后，模型对钢材表面缺陷的分类精度提升了4.2%，验证了注意力机制在缺陷检测任务中的有效性。Chen等[2]的研究也表明，融合注意力机制后，模型在复杂背景下的误检率显著降低。注意力机制通过通道筛选过滤背景噪声干扰，通过空间注意力引导模型关注缺陷所在区域，二者协同作用显著增强了模型对缺陷特征的提取与表达能力。

此外，Hidayatullah等[4]在YOLOv8至YOLO11的架构分析中指出，YOLO系列后续版本在特征融合模块中逐步引入了类注意力机制的设计，如增强空间路径注意力、跨尺度特征校准等，表明注意力机制已成为YOLO架构演进中的重要技术方向。

## 1.3 研究目标与主要工作

本研究以钢材表面缺陷检测为研究对象，基于YOLOv8算法框架，围绕提升检测精度与实用性这一核心目标，开展以下研究工作：

（1）基线模型构建与问题诊断：以YOLOv8s作为基线模型，在NEU-DET数据集上进行系统的训练与评估实验，分析现有模型在钢材六类表面缺陷检测任务上的具体表现，诊断其在检测精度、召回率以及小目标缺陷检测等方面存在的问题，为后续针对性改进提供依据。

（2）CBAM注意力机制改进：将CBAM模块嵌入到YOLOv8的特征融合网络中，增强模型对缺陷特征的关注能力。通过对比不同嵌入位置（颈部网络不同层级）的效果，确定最优的CBAM集成方案。通道注意力负责筛选与缺陷相关的特征通道，过滤背景噪声；空间注意力负责引导模型关注缺陷所在的空间区域，提升定位精度。

（3）损失函数优化：采用WIoU（Wise-IoU）损失函数替代原生CIoU损失函数，通过引入动态锚框质量评估机制，降低简单样本对模型训练的贡献，提升模型在困难样本（遮挡、尺度变化、复杂背景）上的泛化能力，改善整体检测性能的均衡性。

（4）小目标检测层优化：针对钢材表面缺陷中存在大量小尺度缺陷的问题，引入P2高分辨率检测层（特征图尺寸为输入图像的1/4），在原有P3、P4、P5层基础上增加更高分辨率的特征层，提升模型对小尺度缺陷的召回率，降低漏检率。

（5）推理服务系统开发：基于FastAPI框架开发后端推理服务，实现模型加载、图像预处理、批量推理与结果后处理等功能；基于Vue3与Element Plus开发前端交互界面，实现图片上传、缺陷检测、检测结果可视化以及检测记录管理等功能，为工业应用提供便捷的部署方案与友好的用户交互界面。

## 1.4 论文结构安排

本论文共分为五章，各章内容安排如下：

第1章绪论，阐述研究背景与意义，分析工业缺陷检测、YOLO目标检测算法及注意力机制在缺陷检测中应用的国内外研究现状，明确研究目标与主要工作，给出论文结构安排。

第2章相关理论与技术基础，介绍YOLOv8目标检测算法的网络架构与检测原理，阐述CBAM注意力机制的结构与工作原理，分析WIoU损失函数的设计思路，介绍数据增强策略的基本方法。

第3章系统设计与实现，定义钢材表面缺陷检测问题，给出NEU-DET数据集的介绍，详细阐述基线模型设计、CBAM注意力机制改进、损失函数优化、小目标检测层优化等关键技术方案，以及推理服务系统的整体架构设计与模块实现。

第4章实验与分析，介绍实验环境与配置，给出评价指标体系，通过消融实验验证各改进措施的有效性，通过综合对比实验与现有先进方法进行比较，分析系统的综合性能表现。

第5章总结与展望，总结本研究的主要工作与贡献，反思研究过程中的局限性，展望未来可能的研究方向。
