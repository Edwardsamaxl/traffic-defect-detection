# 第1章 绪论

## 1.1 研究背景与意义

工业产品质量是制造业发展的基石，而缺陷检测是保证产品质量的关键环节。在钢铁、汽车零部件等重工业领域，表面缺陷不仅影响产品外观，更可能导致安全隐患和经济损失。据相关统计，工业产品因表面缺陷导致的质量问题占总体质量问题的30%以上[^1]。因此，高效、准确的缺陷检测技术对提升工业产品质量控制水平具有重要意义。

传统的工业缺陷检测主要依靠人工目检和基于机器视觉的自动检测方法。人工目检存在效率低、易疲劳、主观性强等问题，难以满足现代化工业生产的高效率、高质量要求[^2]。基于传统机器视觉的检测方法虽然能够实现一定程度的自动化，但通常依赖人工设计的特征提取器，如边缘检测、纹理分析等方法。这些方法在面对复杂背景、多变缺陷形态时泛化能力较差，难以适应实际工业场景的需求[^2]。

近年来，深度学习技术的快速发展为工业缺陷检测带来了新的解决方案。卷积神经网络（Convolutional Neural Network, CNN）能够自动学习图像特征，避免了人工特征设计的繁琐过程，在图像分类、目标检测等任务上展现出优异性能[^3]。研究表明，基于深度学习的方法在钢材表面缺陷分类任务上取得了显著效果，准确率远超传统方法[^3]。

在众多深度学习目标检测算法中，YOLO（You Only Look Once）系列因其高效的检测速度和良好的精度表现，成为工业缺陷检测领域的首选方案。YOLOv8作为该系列的最新版本，采用anchor-free设计和解耦检测头结构，在保持高精度的同时大幅提升了检测速度，非常适合工业现场的实时检测需求[^4]。

尽管YOLOv8在通用目标检测任务上表现优异，但在处理工业表面缺陷时仍面临一些挑战：缺陷目标普遍较小、形态多样、边界模糊，模型容易出现漏检和误检。针对这些问题，本文提出将CBAM（Convolutional Block Attention Module）注意力机制引入YOLOv8网络，通过增强通道注意力和空间注意力，提升模型对缺陷特征的提取能力，从而提高交通零部件表面缺陷的检测精度。

## 1.2 国内外研究现状

### 1.2.1 工业缺陷检测研究现状

工业缺陷检测一直是计算机视觉领域的研究热点。早期研究主要集中在传统图像处理方法上。Ghosal等人使用边缘检测和纹理分析方法对钢材表面缺陷进行检测[^1]；Liu等人提出了基于局部二元模式（Local Binary Pattern, LBP）的缺陷纹理描述方法[^1]。这些方法在特定场景下取得了一定效果，但泛化能力有限。

随着深度学习技术的发展，基于CNN的方法逐渐成为主流。Cha等人首次将CNN应用于混凝土结构裂缝检测，开启了深度学习在工业缺陷检测中应用的新篇章[^1]。在此基础上，研究者们提出了多种针对工业场景优化的检测网络。2019年，Faghih-Roohi等人使用深度卷积神经网络对钢轨表面缺陷进行分类；2020年，Ye等人提出了基于Faster R-CNN的钢材表面缺陷检测方法[^1]。

工业缺陷检测面临的主要挑战包括：缺陷尺度变化大，从细小的裂纹（几个像素）到较大的斑块（数十个像素）；部分缺陷类别样本数量稀少，存在严重的类别不平衡问题；不同缺陷类别之间形态相似，类间区分困难；缺陷边界模糊，与正常背景对比度低[^1]。这些挑战使得工业缺陷检测成为一项极具难度的任务。

### 1.2.2 目标检测算法研究现状

目标检测是计算机视觉的核心任务之一，旨在定位图像中目标的位置并识别其类别。根据检测流程的不同，目标检测算法可分为两阶段（Two-stage）和单阶段（One-stage）两类。

两阶段检测器以R-CNN系列为代表。2014年，Girshick等人提出R-CNN，首次将CNN应用于目标检测，通过Selective Search生成候选区域，再用CNN提取特征进行分类[^5]。随后，Fast R-CNN和Faster R-CNN相继提出，通过共享特征图和区域提议网络（Region Proposal Network, RPN）大幅提升了检测速度[^5]。两阶段检测器在精度上具有优势，但检测速度较慢，难以满足实时检测需求。

单阶段检测器以YOLO系列为代表，实现了端到端的检测流程。Redmon等人于2016年提出YOLOv1，将目标检测问题转化为单次回归问题，在保证较高精度的同时实现了实时检测[^5]。此后，YOLOv2、YOLOv3、YOLOv4、YOLOv5、YOLOv7等版本相继问世，不断优化网络结构和训练策略。

YOLOv8由Ultralytics公司于2023年发布，在YOLO系列中首次采用anchor-free设计，使用解耦检测头分离分类和定位任务，并引入C2f模块增强特征提取能力[^4]。研究表明，YOLOv8在COCO数据集上取得了优异的精度-速度平衡，其s版本（YOLOv8s）在参数量仅11.2M的情况下达到43.0% mAP@0.5:0.95的精度，推理速度可达280 FPS（GPU）[^4]。

在工业缺陷检测领域，YOLO系列展现出强大的适应性。多项研究将YOLOv8应用于钢材表面缺陷检测，取得了优于传统方法的检测效果[^6][^7]。此外，研究者们还针对工业场景对YOLOv8进行了多方面改进，包括引入注意力机制、增强特征融合、优化损失函数等[^6][^7]。

### 1.2.3 注意力机制在缺陷检测中的应用

注意力机制源于人类视觉系统的认知原理，通过筛选信息重点区域，抑制无关背景，从而提升模型的感知能力。在深度学习中，注意力机制被广泛应用于提升网络对关键特征的关注度。

2018年，Hu等人提出了SE（Squeeze-and-Excitation）模块，通过通道注意力机制自适应校准通道权重，在ImageNet分类任务上取得了显著提升[^8]。同年，Woo等人提出了CBAM模块，在SE模块的基础上增加了空间注意力机制，进一步提升了模型的特征表达能力[^8]。

CBAM由通道注意力模块（Channel Attention Module, CAM）和空间注意力模块（Spatial Attention Module, SAM）顺序连接组成。CAMP通过全局平均池化和最大池化提取通道统计信息，经多层感知机生成通道权重；SAM通过沿通道维度的池化操作生成空间权重图[^8]。这种双重注意力机制使模型能够同时关注"什么"特征重要（通道维度）和"哪里"特征重要（空间维度）。

在工业缺陷检测领域，注意力机制的应用日益广泛。文献表明，融合注意力机制的检测网络能够更好地捕捉缺陷的显著性特征，提升分类和定位的准确性[^6][^7]。例如，SLF-YOLO将轻量化注意力机制融入YOLOv8，在金属表面缺陷检测任务上取得了优于标准YOLOv8的效果[^6]。

然而，现有研究多将注意力机制作为辅助模块直接添加，对注意力机制在缺陷检测中的具体作用机理缺乏深入分析。本文将系统研究CBAM各组件在缺陷检测中的作用，探索通道注意力和空间注意力对不同类型缺陷的差异化影响，为注意力机制在工业检测中的应用提供理论支撑。

## 1.3 研究目标与主要工作

本文以交通零部件表面缺陷检测为研究对象，以YOLOv8为基础框架，研究注意力机制对缺陷检测精度的影响及其作用机理。具体研究目标如下：

1. 构建基于YOLOv8s的缺陷检测基线模型，在NEU-DET钢材表面缺陷数据集上验证模型性能；

2. 将CBAM注意力机制集成到YOLOv8网络中，研究CBAM不同插入位置对检测效果的影响；

3. 通过消融实验定量分析通道注意力和空间注意力对各类缺陷检测的贡献；

4. 对比不同训练策略（输入分辨率、数据增强方法）对最终性能的影响。

围绕上述目标，本文的主要工作包括：

1. **基线模型构建**：使用标准YOLOv8s在NEU-DET数据集上训练，建立性能基准；

2. **CBAM集成方案设计**：在YOLOv8的Backbone网络中C2f模块后插入CBAM模块，实现通道维度和空间维度的双重注意力增强；

3. **消融实验设计**：分别验证CBAM各组件、输入分辨率、数据增强策略的单独效果和组合效果；

4. **性能评估与分析**：从检测精度、分类准确性、定位精度等多维度评估改进方案的有效性。

## 1.4 论文结构安排

本文共分为五章，各章内容安排如下：

第一章为绪论，阐述研究背景与意义，综述国内外研究现状，明确本文的研究目标与主要工作。

第二章为理论基础与文献综述，介绍卷积神经网络的基本原理，阐述目标检测算法的发展历程，详细讲解YOLOv8的核心架构，以及CBAM注意力机制的原理与实现。

第三章为系统设计与实现，描述基于YOLOv8的缺陷检测系统整体架构，详细介绍CBAM模块的集成方案，以及训练过程中的关键策略。

第四章为实验与分析，介绍实验环境与评价指标，展示CBAM消融实验和对比实验的结果，并进行深入分析。

第五章为总结与展望，总结本文的研究工作和主要贡献，并对未来研究方向进行展望。
