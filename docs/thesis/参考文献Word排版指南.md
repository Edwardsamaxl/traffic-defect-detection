# 参考文献 Word 排版指南

## 一、基础格式要求（常见学位论文规范）

| 项目 | 要求 |
|------|------|
| 标题 | "参考文献"四字，黑体/宋体加粗，三号或小二号，居中 |
| 正文字体 | 宋体/Times New Roman，五号或小四号 |
| 行距 | 1.5倍行距或固定值20磅 |
| 对齐 | 两端对齐 |
| 缩进 | **悬挂缩进** 2字符（见下方设置方法） |
| 序号格式 | `[1]` 顶格，序号后空一格再接正文 |

---

## 二、关键操作：悬挂缩进（最重要）

**效果**：序号 `[1]` 顶格对齐，第二行开始的内容自动缩进，整齐美观。

### 设置步骤：

1. **选中全部参考文献**（从 `[1]` 到 `[27]`）
2. 点击菜单栏 **"开始" → "段落"** 右下角小箭头（打开段落设置框）
3. 在 **"缩进和间距"** 标签页：
   - **特殊格式**：选择 **"悬挂缩进"**
   - **磅值**：设置为 **"2字符"**（或根据学校要求设为 "0.74厘米"）
4. 点击确定

> 快捷操作：也可以拖动标尺上的 **"悬挂缩进"滑块**（倒三角形状）到合适位置。

---

## 三、设置段前段后空行（你问的"空两行"）

如果学校要求**每条参考文献之间空一行或两行**：

### 方法：设置段后间距

1. 选中全部参考文献
2. 打开 **"段落"** 设置框
3. 在 **"间距"** 区域：
   - **段后**：设置为 **"1行"** 或 **"2行"**（或固定值 "12磅" / "24磅"）
4. 点击确定

### 常见问题：
- **如果空行太大**：把段后间距改为 **"0.5行"** 或 **"6磅"**
- **如果标题和第一条文献之间也要空行**：单独选中标题，设置 **段后 1行**

---

## 四、快速统一格式：使用"样式"功能（推荐）

如果你后续还要修改，建议创建一个 **"参考文献"样式**，方便统一管理。

### 创建步骤：

1. 选中一条已经调好格式的参考文献
2. 点击 **"开始" → "样式"** 窗格 → **"创建样式"**
3. 命名为 **"参考文献"**
4. 以后每次写新的参考文献，直接应用这个样式即可

---

## 五、从当前文件复制到 Word 的注意事项

1. **不要直接复制 Markdown 的 `#` 标题符号**，在 Word 里手动输入"参考文献"四个字
2. **去掉 `>` 引用符号**，那个只是 Markdown 的提示语法
3. **英文作者名中的 `,` 和 `.` 后空一格**，如 `WOO S, PARK J`
4. **`[1]` 和正文之间空一格**，如 `[1] WOO S...`（当前文件已符合）

---

## 六、一键检查清单

粘贴到 Word 后，按顺序检查：

- [ ] 删除 Markdown 格式符号（`#`、`>`）
- [ ] 设置标题"参考文献"的字体字号（黑体/宋体加粗，居中）
- [ ] 设置正文字体（宋体/Times New Roman，五号）
- [ ] 设置悬挂缩进 2 字符
- [ ] 设置行距（1.5倍或固定值20磅）
- [ ] 设置段后间距（如要求条目间空行）
- [ ] 检查英文标点后的空格是否统一
- [ ] 检查 `[12]` 的 `[A/OL]` 格式是否保留（等找到页码再改回 `[J]`）
