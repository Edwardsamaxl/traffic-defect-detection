# 第三章第四节：模型库说明

> 本文档详细说明 `experiments/thesis_model/` 下所有模型的设计动机、技术原理和实验定位。
> 数据集：NEU-DET（6类钢铁表面缺陷：crazing, inclusion, patches, pitted_surface, rolled-in_scale, scratches）
> 基线模型：YOLOv8s，输入分辨率 640×640

---

## 0. 关键概念澄清：P2/P3/P4/P5 的两种不同含义

> ⚠️ **容易混淆的点**：YOLOv8 中 P2/P3/P4/P5 这套命名在 **backbone** 和 **检测 head** 里含义不同。

### Backbone 里的 "P" = 降采样阶段标记

| backbone层索引 | 注释 | 含义 |
|-------------|------|------|
| 0 | P1/2 | 第1次卷积，stride=2 |
| 1 | P2/4 | 第2次卷积，stride=4 |
| 3 | P3/8 | 第3次卷积，stride=8 |
| 5 | P4/16 | 第4次卷积，stride=16 |
| 7 | P5/32 | 第5次卷积，stride=32 |

**标准 YOLOv8 的 backbone 在第1层就已经有 P2/4**，它只是特征提取的一个中间阶段，**不作为检测层输出**。

### 检测 Head 里的 "P" = 输出检测层

| 检测层 | 特征图尺寸（输入640时） | 负责目标尺寸 |
|-------|----------------------|------------|
| **P2**（可选） | 160×160 | 极小目标 |
| **P3** | 80×80 | 小目标 |
| **P4** | 40×40 | 中目标 |
| **P5** | 20×20 | 大目标 |

标准 YOLOv8 **只有 P3/P4/P5 三个检测层**。加上 P2 需要修改 head 结构（`yolov8-p2.yaml`）。

### CBAM 插入位置是 Backbone 阶段，不是检测层

> CBAM 插在 backbone 的 **P2/4 阶段后、P3/8 阶段后、P4/16 阶段后**。
> 这里的 P2/P3/P4 是降采样阶段名，不是检测层。
> cbamp3.pt / cbamp4.pt / cbamp5.pt 中的 P3/P4/P5 也是指降采样阶段。

## 二、基线模型

### 2.1 baseline.pt — 标准Baseline (640)
- **对应实验**: `src/experiments/exp01_high_resolution/train_1024.py`（训练name为exp01_baseline_640）
- **模型配置**: `ultralytics/cfg/models/v8/yolov8s.yaml`
- **输入分辨率**: 640×640
- **检测层**: P3/P4/P5（共3个）
- **训练参数**: epochs=200, patience=50, batch=4, mosaic=1.0, mixup=0.1
- **定位**: 所有其他优化实验的公平对照基准

### 2.2 baseline1024.pt — 高分辨率Baseline
- **对应实验**: `src/experiments/exp01_high_resolution/train_1024.py`
- **输入分辨率**: **1024×1024**（其余同baseline）
- **定位**: 对比分辨率提升（640 vs 1024）对缺陷检测的影响
- **理论依据**: 更高分辨率可保留更多细粒度纹理信息，有助于检测细裂纹(crazing)和微小划痕(scratches)

## 三、注意力机制

### 3.1 cbam.pt — CBAM注意力机制
- **对应实验**: `src/experiments/exp02_cbam_attention/train_cbam.py`
- **模型配置**: `yolov8s_cbam.yaml`
- **CBAM插入位置**: backbone的 **P2/4阶段后、P3/8阶段后、P4/16阶段后**（共3处）
- **CBAM结构**:
  - **CAM（通道注意力）**: MaxPool + AvgPool → MLP → Sigmoid，生成通道权重
  - **SAM（空间注意力）**: 通道压缩后 → 7×7Conv → Sigmoid，生成空间权重
- **检测层**: P3/P4/P5（3个，与baseline相同）
- **定位**: 验证注意力机制对缺陷特征提取的增强效果
- **理论依据**: CBAM能帮助模型区分不同缺陷类型（通道注意力）并定位缺陷区域（空间注意力）

### 3.2 se.pt — SE注意力机制
- **对应实验**: `experiments/exp10_se/args.yaml`
- **模型配置**: `yolov8s_se_gfpn.yaml`
- **核心改进**: 使用**Squeeze-and-Excitation (SE)** 模块替代CBAM
- **SE结构**: Global AvgPool → FC → ReLU → FC → Sigmoid → 通道权重（仅通道注意力，无空间注意力）
- **定位**: 对照实验，验证通道注意力（SE）与空间+通道注意力（CBAM）的效果差异

### 3.3 cbamp3+p4.pt / cbamp3.pt / cbamp4.pt / cbamp5.pt — CBAM位置消融
- **对应实验**: `src/experiments/exp11_ablation_cbam_position/train_ablation.py`
- **模型配置**: `yolov8s_cbam_p3only.yaml` / `yolov8s_cbam_p4only.yaml` / `yolov8s_cbam_p5only.yaml` / `yolov8s_cbam_p3p4.yaml`
- **核心改进**: 消融CBAM插入的降采样阶段位置，验证哪一处对检测性能贡献最大
  - `cbamp3.pt`: CBAM **仅**在 **P3/8阶段后**（backbone索引6的位置）
  - `cbamp4.pt`: CBAM **仅**在 **P4/16阶段后**（backbone索引9的位置）
  - `cbamp5.pt`: CBAM **仅**在 **P5/32阶段后**（backbone索引...的位置）
  - `cbamp3+p4.pt`: CBAM在 **P3/8和P4/16阶段后**（共2处）
- **注意**: cbamp3/4/5 中的 P3/P4/P5 是**降采样阶段名**（backbone层），不是检测层
- **定位**: 消融实验，明确CBAM最优插入位置
- **理论依据**: 浅层特征（P3/8附近）空间细节丰富但语义弱；深层特征（P5/32附近）语义强但空间分辨率低。CBAM位置影响不同尺度缺陷的检测效果。

## 四、多尺度检测优化

### 4.1 p2_layer.pt — P2高分辨率检测层
- **对应实验**: `src/experiments/exp03_p2_layer/train_p2.py`
- **模型配置**: `yolov8s-p2.yaml`
- **核心改进**: **添加P2检测层**，检测头从3个变成4个（P2/P3/P4/P5）
- **技术原理**: P2检测层特征图尺寸为160×160（输入640时），是P3（80×80）的4倍，可以检测更小的目标
- **定位**: 优化极小尺寸缺陷（细裂纹crazing、微小划痕scratches）的检测
- **理论依据**: NEU-DET中crazing和scratches往往尺寸极小，标准YOLOv8的最小检测层P3可能不够

### 4.2 cbam_p2.pt — CBAM + P2组合
- **对应实验**: `src/experiments/exp04_combined/train_combined.py`
- **模型配置**: `yolov8s_cbam_p2.yaml`（需确认存在）
- **核心改进**: 结合CBAM注意力 + P2高分辨率检测层（共4个检测头）
- **定位**: 组合多种优化策略，追求最佳检测性能
- **理论依据**: CBAM增强特征提取，P2层提供高分辨率，协同提升小缺陷检测

## 五、下采样优化

### 5.1 cbam_spd.pt — CBAM + SPD-Conv
- **对应实验**: `src/experiments/exp07_spd_conv/train_spd_conv.py`
- **模型配置**: `yolov8s_cbam_spdconv.yaml`
- **核心改进**: Backbone前两层下采样用**SPD-Conv**替代传统stride=2卷积
- **SPD-Conv原理**:
  - 传统stride=2卷积：每步采样丢弃75%空间信息
  - SPD-Conv：Space-to-Depth将空间信息重组到通道维度 → 非步长卷积 → 保持细粒度信息
- **实验设计**: SPD-Conv在backbone前两层（对应P1/2和P2/4阶段） + 保留CBAM注意力
- **定位**: 验证SPD-Conv对细粒度缺陷检测的增益

### 5.2 spd_only.pt — 纯SPD-Conv（无CBAM）
- **对应实验**: `src/experiments/exp08_spd_only/train_spd_only.py`
- **模型配置**: `yolov8s_spdconv.yaml`（无CBAM）
- **核心改进**: 仅使用SPD-Conv，不使用CBAM注意力
- **定位**: 对照实验，分离SPD-Conv与CBAM的独立贡献

## 六、Neck架构优化

### 6.1 cbam_gfpn_neck.pt — CBAM(Backbone) + GFPN Neck
- **对应实验**: `src/experiments/exp09_cbam_gfpn_neck/train_gfpn.py`
- **模型配置**: `yolov8s_cbam_gfpn.yaml`
- **核心改进**: CBAM放在backbone（与exp02相同），但Neck由标准PANet替换为**GFPN**（Ghost Feature Pyramid Network）
- **GFPN原理**: 通过Ghost卷积生成更多特征图，减少计算量同时保持特征丰富度
- **定位**: 对照实验，验证GFPN Neck相比标准PANet的效果差异

## 七、损失函数优化

### 7.1 wiou.pt — WIoU v3损失
- **对应实验**: `src/experiments/exp06a_wiou/train_wiou.py`
- **核心改进**: 用**WIoU v3**替代默认CIoU作为边界框回归损失
- **WIoU v3原理**:
  - 构建单调聚焦系数，减弱"困难样本"（离群样本）对训练的干扰
  - 同时保留困难样本的有用梯度信息，避免梯度衰减
  - β参数控制对离群样本的惩罚程度
- **定位**: 改进边界框回归，尤其适用于缺陷长宽比差异大（细裂纹vs斑块）的场景

### 7.2 focal.pt — Focal Loss难分类优化
- **对应实验**: `src/experiments/exp06b_focal/train_focal.py`
- **核心改进**: 使用**Focal Loss**替代BCE分类损失
- **Focal Loss原理**: FL(p) = -α·(1-p)^γ·log(p)，γ=2.0
  - γ=0: 退化为普通BCE
  - γ越大: 越聚焦于难分类样本
- **定位**: 解决crazing类别recall极低（0.176）的问题，增强对难分类缺陷的学习

## 八、数据增强优化

### 8.1 data_augmentation.pt — 增强数据增强策略
- **对应实验**: `src/experiments/exp05_augmentation/train_augmented.py`
- **模型配置**: `yolov8s.yaml`（标准模型，仅改增强参数）
- **核心改进**: 更激进的数据增强配置
  - MixUp: 0.1 → **0.15**
  - HSV色调: 0.015 → **0.02**，饱和度: 0.7 → **0.6**，亮度: 0.4 → **0.5**
  - 旋转范围: 5° → **10°**
  - 平移范围: 0.1 → **0.15**
  - **新增**: shear=2.0, perspective=0.0005, erasing=0.4
- **定位**: 提升模型对各种缺陷变体的泛化能力，减少过拟合
- **理论依据**: 钢铁表面光照不均、纹理差异大，增强数据增强可模拟这些变化

## 九、实验分类总结

### 按优化维度分类

| 优化维度 | 模型 | 核心技术 |
|---------|------|---------|
| **注意力机制** | cbam.pt, se.pt, cbamp3.pt, cbamp4.pt, cbamp5.pt, cbamp3+p4.pt | CBAM / SE模块，插入backbone降采样阶段后 |
| **多尺度检测** | p2_layer.pt, cbam_p2.pt | P2检测层（增加第4个检测头） |
| **下采样优化** | cbam_spd.pt, spd_only.pt | SPD-Conv替代stride=2卷积 |
| **Neck架构** | cbam_gfpn_neck.pt | GFPN替代标准PANet |
| **损失函数** | wiou.pt, focal.pt | WIoU边界框损失 / Focal分类损失 |
| **数据增强** | data_augmentation.pt | 激进增强策略 |
| **分辨率** | baseline1024.pt | 1024×1024输入 |

### 按消融层级分类

| 层级 | 模型 | 说明 |
|-----|------|-----|
| **Baseline** | baseline.pt, baseline1024.pt | 对照基准 |
| **单因素优化** | cbam.pt, p2_layer.pt, wiou.pt, focal.pt, data_augmentation.pt | 单一变量 |

| **组合优化** | cbam_p2.pt | CBAM + P2组合（注意力+多尺度） |

## 十一、预期实验结论方向

1. **CBAM有效性**: cbam.pt vs baseline.pt → 注意力机制对缺陷检测的提升幅度
2. **P2层必要性**: p2_layer.pt vs baseline.pt → 高分辨率检测层对小缺陷的增益
3. **SPD-Conv价值**: cbam_spd.pt vs cbam.pt, spd_only.pt vs baseline.pt → 下采样优化独立贡献
4. **CBAM插入位置**: cbamp3/4/5/3p4 vs cbam.pt → 消融最优CBAM位置（哪个降采样阶段最关键）
5. **组合效果**: cbam_p2.pt vs cbam.pt + p2_layer.pt → 多种优化是否协同生效
6. **GFPN Neck**: cbam_gfpn_neck.pt vs cbam.pt → Neck架构对性能的影响
7. **损失函数**: wiou.pt vs focal.pt → 边界框损失 vs 分类损失的各自侧重效果
8. **注意力对比**: se.pt vs cbam.pt → 通道注意力 vs 通道+空间注意力的效果差异
