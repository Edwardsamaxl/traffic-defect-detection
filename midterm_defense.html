研究背景

问题定义与研究动机

1

工业质检需求迫切 — 人工检测效率低、成本高、漏检率高；钢材表面缺陷直接影响产品质量和使用安全

2

标注数据获取困难 — 缺陷检测需要专业领域知识，标注效率低、成本高；深度学习模型依赖大量标注数据

3

数据分布不均衡 — 各类缺陷样本数量差异大；部分缺陷（如crazing）样本稀少，检测困难

4

伪标签质量控制 — 如何筛选高质量伪标签是半监督学习成功的关键；低质量伪标签会导致误差累积

核心方法：三大半监督策略

01

YOLOv8s 基线模型

采用 YOLOv8s 作为检测器，在精度与速度间取得良好平衡。11.1M 参数，适合工业场景部署。

Backbone: CSPDarknet + C2f + SPPF
Neck: PAFPN | Head: Decoupled

损失函数：CIoU + Focal Loss + DFL

02

自适应置信度阈值

根据每类AP动态调整阈值：AP高的类别用低阈值捕获更多正样本，AP低的类别用高阈值保证质量。

threshold[c] = base + λ × (1 - norm_APc)

例如：scratches (AP高) → 低阈值
crazing (AP低) → 高阈值

03

翻转一致性筛选

原图与水平翻转图双重预测，仅保留IoU≥0.6匹配且类别一致的检测框，大幅提升伪标签可靠性。

if IoU(boxorig, boxflip) ≥ τ:
    accept pseudo-label

τ = 0.6 (IoU阈值)

标注数据 (378张) + 无标注数据 (882张) → 伪标签生成 → 混合训练 → 缺陷检测模型
