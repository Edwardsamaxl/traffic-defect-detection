## 4.2 基线模型：YOLOv8s

### 4.2.1 模型架构

YOLOv8是Ultralytics公司开发的最新YOLO版本，在精度和速度之间取得了良好平衡。

```
Backbone (CSPDarknet)
    ├── Conv + C2f + SPPF
    └── 特征金字塔

Neck (PAFPN)
    ├── Top-down路径
    └── Bottom-up路径

Head (Decoupled Detection Head)
    ├── Classification (cls)
    └── Bounding Box (reg)
```

### 4.2.2 损失函数

YOLOv8采用复合损失函数：

$$
L_{total} = \alpha \cdot L_{box} + \beta \cdot L_{cls} + \gamma \cdot L_{dfl}
$$

其中：

- **Box Loss (CIoU)**：边界框回归精度
- **Cls Loss (Focal)**：分类损失，处理类别不平衡
- **DFL Loss**：分布焦点损失，精细化边界框

## 4.3 半监督策略

### 4.3.1 问题定义

给定：
- 标注数据集 $D_l = \{(x_i, y_i)\}_{i=1}^{N_l}$（378张图像）
- 无标注数据集 $D_u = \{x_j\}_{j=1}^{N_u}$（882张图像）

目标：利用 $D_u$ 提升模型性能

### 4.3.2 动态置信度阈值

#### 动机

固定置信度阈值的问题：
- 不同类别的检测难度差异大
- AP高的类别（如scratches）应该使用较低阈值
- AP低的类别（如crazing）应该使用较高阈值

#### 方法

**第一步**：训练监督学习基线，获取各类别AP

$$
\text{AP}_c = \text{计算类别}c\text{的Average Precision}
$$

**第二步**：计算自适应阈值

$$
\text{threshold}_c = \text{base\_conf} + \lambda \cdot (1 - \text{norm\_AP}_c)
$$

其中：

$$
\text{norm\_AP}_c = \frac{\text{AP}_c - \min(\text{AP})}{\max(\text{AP}) - \min(\text{AP}) + \epsilon}
$$

#### 阈值计算示例

| 类别 | AP | norm_AP | threshold (base=0.65, λ=0.25) |
|------|-----|---------|------------------------------|
| scratches | 0.75 | 1.00 | 0.65 |
| inclusion | 0.60 | 0.50 | 0.775 |
| patches | 0.55 | 0.40 | 0.85 |
| rolled-in_scale | 0.50 | 0.30 | 0.925 |
| pitted_surface | 0.45 | 0.15 | 1.00 (clamped) |
| crazing | 0.40 | 0.00 | 0.95 |

#### 核心代码

```python
def compute_adaptive_threshold(
    baseline_ap: list[float],
    class_id: int,
    base_conf: float = 0.65,
    lambda_val: float = 0.25
) -> float:
    """
    根据类别AP计算自适应阈值

    AP低的类别使用更高阈值，AP高的类别使用更低阈值
    """
    ap = baseline_ap[class_id]
    ap_min = min(baseline_ap)
    ap_max = max(baseline_ap)

    # 归一化AP到[0,1]
    norm = (ap - ap_min) / (ap_max - ap_min + 1e-9)

    # 计算阈值
    threshold = base_conf + lambda_val * (1 - norm)

    # 限制在合理范围
    return max(0.3, min(0.95, threshold))
```

### 4.3.3 翻转一致性筛选

#### 动机

单次预测可能存在以下问题：
- 边界框位置不稳定
- 置信度波动
- 假阳性检测

通过翻转一致性验证，可以筛选出更可靠的伪标签。

#### 方法

```
原图预测                    翻转图预测
    │                          │
    ▼                          ▼
┌─────────┐                ┌─────────┐
│ Boxes   │                │ Boxes   │
└────┬────┘                └────┬────┘
     │                          │
     │                     (x' = 1 - x)
     │                          │
     ▼                          ▼
┌─────────────────────────────────┐
│      IoU匹配 + 类别一致性        │
│  IoU(box, flip_box) >= τ        │
└────────────────┬────────────────┘
                 │
                 ▼
         保留伪标签
```

#### 算法步骤

1. **原图预测**：对原始图像进行目标检测
2. **翻转预测**：对水平翻转图像进行检测
3. **坐标映射**：将翻转图的边界框x坐标映射回原图坐标
   - $x_{mapped} = 1.0 - x_{flip}$
4. **IoU匹配**：对于每个原图检测框，找到翻转图中相同类别的最佳匹配
5. **一致性验证**：仅保留IoU ≥ τ的检测框
6. **置信度融合**：使用 $\min(conf_{orig}, conf_{flip})$ 作为最终置信度

#### 核心代码

```python
def flip_consistency_filter(
    boxes_orig: list[Box],
    boxes_flip: list[Box],
    iou_threshold: float = 0.6
) -> list[Box]:
    """
    翻转一致性筛选

    只保留原图和翻转图预测一致的目标框
    """
    valid_boxes = []

    for box in boxes_orig:
        matched = False

        for flip_box in boxes_flip:
            # 类别必须一致
            if flip_box.class_id != box.class_id:
                continue

            # IoU匹配
            iou = compute_iou(box.xyxy, flip_box.mapped_xyxy)
            if iou >= iou_threshold:
                matched = True
                break

        if matched:
            # 使用较低的置信度
            box.confidence = min(box.confidence, flip_box.confidence)
            valid_boxes.append(box)

    return valid_boxes
```

### 4.3.4 Seed数据强化

#### 动机

伪标签虽然经过筛选，但质量仍不如真实标签。需要平衡两者对训练的影响。

#### 方法

**策略**：复制Seed数据，降低伪标签相对权重

| 数据类型 | 复制次数 | 相对权重 |
|---------|---------|---------|
| Seed (标注数据) | 3× | 1.0 |
| 伪标签数据 | 1× | 0.5 (有效) |

**效果**：
- Seed数据出现3次，每个epoch被学习3次
- 伪标签数据只出现1次，但权重为0.5
- 等效于伪标签权重降低至 ~0.17
